# Student ID Card Generator

**Team: Ignite**

A simple web app built with HTML, CSS and basic JavaScript. Users enter their details and upload a photo, and the app instantly generates a digital student ID card that can be printed or saved as a PDF.

## Features

- Form to enter name, roll number, course, year, phone and email
- Profile photo upload
- Instant ID card generation
- Print or save the card as PDF
- Responsive design for mobile and desktop

## Technologies Used

- HTML
- CSS
- JavaScript
- Visual Studio Code
- Web Browser

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

## How to Use

1. Fill in all the student details in the form.
2. Choose a profile photo.
3. Click **Generate ID Card**.
4. Click **Print ID Card** to print or save it as PDF.
